# 注册即产生的 30 天试用订单

## 逻辑

- 用户创建空间（`public.spaces` INSERT）后，由数据库触发器 **`trg_spaces_crm_on_created`** 调用 **`crm.on_space_created()`**，除运营分配外自动插入一条 **`crm.space_orders`** 试用在服订单，以便主应用通过 **`crm.get_space_entitlements(space_id)`** 读取权益。
- SKU 编码（`crm.sku_edition.code`）  
  - Client 空间：`CLIENT_TRIAL_30`  
  - Firm 空间：`FIRM_TRIAL_30`
- 订单字段约定  
  - `status` = `active`  
  - `started_at` = `now()`  
  - `expires_at` = `now() + interval '30 days'`  
  - `source` = `registration`  
  - `metadata` 可为 `{}`

## 存量空间

- 一次性迁移可为尚无在服订阅（`billing_kind = space_subscription` 且未过期）的空间补插从 **`2026-05-01` UTC** 起 30 天的试用单（`source = ops_grant`），见 Vouchap 仓库迁移 `20260512100000_subscription_entitlements_orders.sql`。

## 查询 SKU id（示例）

```sql
SELECT id, code FROM crm.sku_edition WHERE code IN ('CLIENT_TRIAL_30', 'FIRM_TRIAL_30');
```
